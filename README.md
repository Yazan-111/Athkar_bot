# Athkar_bot
It is a bot on Telegram based on the n8n automation system. It helps the user to adhere to daily supplications, such as: morning and evening supplications, sleep supplications, and others.
It provides all the supplications (adhkar) found in the booklet "Hisnul Muslim" by the author Sa'id bin Wahf al-Qahtani.
I hope that this bot serves as an ongoing charity (sadaqah jariyah) on behalf of both me and him.
